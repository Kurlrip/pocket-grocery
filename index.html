Comment jouer
  1. Dans Construire, choisissez un rayon. Sur téléphone, touchez une case pour afficher l’aperçu, puis appuyez sur Poser. Sur PC, un clic pose le rayon.
  2. Hors construction, touchez ou cliquez à la base d’un rayon pour le tourner ou le retirer.
  3. Chaque client cherche un produit. Consultez les demandes manquées dans Construire. Votre employé réapprovisionne les rayons.
  4. Remplissez les objectifs pour gagner des primes.
